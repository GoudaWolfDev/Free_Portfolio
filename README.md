## 🌐 English Description

### Overview
This repository contains a **free, open-source, and fully customizable portfolio template** designed for developers, tech entrepreneurs, ethical hackers, and security researchers.

Anyone can freely clone, modify, customize, and deploy this project as their own personal website or portfolio.

### ✨ Highlights & Features
- **100% Free & Open Source**: Free for personal and commercial use under the MIT License.
- **Cyberpunk / Corporate Dark Theme**: High-end modern UI built with Tailwind CSS, Lucide Icons, and Font Awesome.
- **Interactive 3D Visuals**: Three.js background and particle effects for a distinctive user experience.
- **Ready-to-Use Portfolio Sections**:
  - Hero introduction with dynamic headlines.
  - Skills, tech stack, and cybersecurity specializations.
  - Featured projects list with details page (`portfolio.php`, `details.php`).
  - About me and career milestones (`about.php`).
- **Interactive Backend Components**:
  - Functional contact form with **PHPMailer** support (`contact_handler.php`).
  - Integrated smart assistant / chatbot script (`chatbot_handler.php`).
- **Responsive & Bilingual-Ready**: Optimized layout supporting both English and Arabic typography (Cairo & Inter fonts).

### 🛠️ Tech Stack
- **Backend**: PHP 8.x (OOP)
- **Email Handler**: PHPMailer 7.x
- **Frontend**: HTML5, Vanilla JavaScript, Tailwind CSS (via CDN), Three.js
- **Icons & Fonts**: Font Awesome, Lucide Icons, Google Fonts (Inter, Cairo)

### 🚀 How to Use / Customize for Yourself

1. **Clone or Download the Template:**
   ```bash
   git clone https://github.com/yourusername/web-site-of-gouda_nasralla.git
   ```

2. **Move into your Web Server Folder:**
   Place the project inside your local web server root (e.g. `htdocs` in XAMPP or `www` in WAMP/LAMP).

3. **Install Dependencies:**
   ```bash
   composer install
   ```

4. **Personalize Your Information:**
   - Update your personal info, titles, bio, and social links in `index.php` and `about.php`.
   - Replace profile avatar/images (e.g. `me.png`) with your own.
   - Configure your SMTP mail credentials in `contact_handler.php`.
   - Add your own projects in `portfolio.php` and `details.php`.

5. **Run Locally:**
   Start Apache and visit:
   ```text
   http://localhost/web-site-of-gouda_nasralla/
   ```
