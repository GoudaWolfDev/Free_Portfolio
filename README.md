## 🌐 English Description

### Overview
A modern, dark-mode cyberpunk/corporate fusion portfolio website for **Gouda Nasralla**, Tech Entrepreneur and Security Researcher. The project showcases projects, technical skills, ethical hacking expertise, and contact mechanisms including an interactive contact form and automated chatbot assistant.

### Key Features
- **Modern UI/UX**: Dark mode styling with cyberpunk/corporate aesthetic powered by Tailwind CSS, Font Awesome, and Lucide Icons.
- **3D Graphics & Animations**: Interactive visual elements integrated with Three.js.
- **Project Showcase**: Dedicated pages for portfolio projects, research, and technical achievements (`portfolio.php`, `details.php`).
- **Contact & Interaction**:
  - Email messaging powered by **PHPMailer** (`contact_handler.php`).
  - Interactive AI/Automated Chatbot Assistant (`chatbot_handler.php`).
- **Bilingual Typography**: Clean typography with Google Fonts (Inter & Cairo).

### Tech Stack
- **Backend**: PHP 8.x (OOP)
- **Email Service**: PHPMailer 7.x (via Composer)
- **Frontend**: HTML5, Vanilla JavaScript, Tailwind CSS, Three.js, Lucide Icons, Font Awesome
- **Server Environment**: Apache / XAMPP

### Getting Started

1. **Clone or copy repository:**
   ```bash
   git clone https://github.com/yourusername/web-site-of-gouda_nasralla.git
   ```

2. **Place in Web Server Directory:**
   Move or place the project folder in your local server root (e.g., `C:/xampp/htdocs/web-site-of-gouda_nasralla`).

3. **Install Dependencies:**
   ```bash
   composer install
   ```

4. **Run the Application:**
   Start Apache via XAMPP and open your browser at:
   ```text
   http://localhost/web-site-of-gouda_nasralla/
   ```
